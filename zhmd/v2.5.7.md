# v2.5.7 技术文档：旧版节点移除（`NunchakuQwenImageLoraStack`）

> 基线提交：`a3c2ed1`（v2.5.6）
> 提交：`88ed1a3`（功能与文档）/ `7ae12b7`（版本与更新日志）

---

## ① 目的

从节点注册映射（`NODE_CLASS_MAPPINGS`、`NODE_DISPLAY_NAME_MAPPINGS`）以及相关文档中移除旧版节点 **`NunchakuQwenImageLoraStack`**（"Nunchaku Qwen Image LoRA Stack (Legacy)"）。

随着现代堆叠器实现（`NunchakuQwenImageLoraStackV1`、`V2` 和 `V3`）的成熟与广泛使用，早期的旧版实现已被淘汰，以精简节点库、防止工作流混淆并消除维护负担。

### 要求与范围
1. **取消旧版节点注册**：在 `__init__.py` 中从 `NODE_CLASS_MAPPINGS` 和 `NODE_DISPLAY_NAME_MAPPINGS` 中移除 `NunchakuQwenImageLoraStack`。
2. **对其他节点零影响**：单 LoRA 加载器（`NunchakuQwenImageLoraLoader`）、现代堆叠器（`NunchakuQwenImageLoraStackV1`、`V2`、`V3`）、Z-Image-Turbo 堆叠器（`V1`、`V4`）、Krea2 ControlNet 加载器（`Krea2ControlNetLoraLoader`）以及 DiffSynth ControlNet 节点（`NunchakuQI&ZITDiffsynthControlnet`）完全不受任何影响。
3. **文档清理**：从 `README.md` 和 `zhmd/README.md` 中删除旧版节点引用、预览图片和配置说明。
4. **编码与完整性**：确保所有修改文件 100% 保持 UTF-8 编码，绝无乱码（Mojibake）。

## ④ 详细技术说明

### 4.1 节点注册体系架构（v2.5.7 之后）

本次发布后，当前有效注册的节点体系如下：

| 分类 | 注册节点 | 目标模型 | UI 类型 |
|---|---|---|---|
| **单 LoRA 加载器** | `NunchakuQwenImageLoraLoader` | Nunchaku Qwen Image | 标准下拉选择 |
| **Qwen Image 堆叠器** | `NunchakuQwenImageLoraStackV1` | Nunchaku Qwen Image | rgthree 风格行布局 |
| | `NunchakuQwenImageLoraStackV2` | Nunchaku Qwen Image | 动态槽位 UI（含 AWQ Mod 开关） |
| | `NunchakuQwenImageLoraStackV3` | Nunchaku Qwen Image | 动态槽位 UI（自动 AWQ Mod） |
| **Z-Image-Turbo 堆叠器** | `NunchakuZImageTurboLoraStackV1` | Nunchaku Z-Image-Turbo | rgthree 风格行布局 |
| | `NunchakuZImageTurboLoraStackV4` | Nunchaku Z-Image-Turbo | 动态槽位 UI（CLIP 透传） |
| **ControlNet 与适配器** | `Krea2ControlNetLoraLoader` | Krea2 / SingleStreamDiT | Depth / OpenPose 自动检测 |
| | `NunchakuQI&ZITDiffsynthControlnet` | Qwen Image, Z-ImageTurbo, Krea2 | 统一 ControlNet 条件应用 |

### 4.2 迁移指南

此前使用 `NunchakuQwenImageLoraStack`（旧版）的工作流应更新为以下替代方案之一：

- **标准画布 / rgthree 风格紧凑 UI**：使用 `NunchakuQwenImageLoraStackV1`。
- **动态槽位增减 & Nodes 2.0 (Beta) 兼容**：使用 `NunchakuQwenImageLoraStackV3`（推荐，内置自动 AWQ 调制层支持）或 `NunchakuQwenImageLoraStackV2`。
- **单个 LoRA 加载**：使用 `NunchakuQwenImageLoraLoader`。
