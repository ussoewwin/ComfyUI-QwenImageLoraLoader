# v2.6.1 技术文档：LoRA 型 ControlNet 在 Nunchaku Qwen Image 上的调查结论

> 版本提交：`76bf0e7` - `changelog(zh): add v2.6.1 entry`
> 日期：2026-08-29

---

## 概述

本次发布记录了对 **LoRA 型 ControlNet** 在 **Nunchaku Qwen Image** 上的全面调查。

**结论：LoRA 型 ControlNet 无法用于 Nunchaku Qwen Image。** README 的 Known Limitations 部分已补充完整的技术背景（model-patch 型与 LoRA 型）。

---

## 1. 调查内容

### LoRA 型 ControlNet（例如 `qwen_image_union_diffsynth_lora.safetensors`）

- 该 LoRA（来自 **Comfy-Org** 的 Qwen-Image-DiffSynth-ControlNets，原为 **DiffSynth-Studio** 的 Qwen-Image-In-Context-Control-Union）是对**全部 60 个 transformer 块的 rank 64 全量 LoRA**（覆盖所有 attention / MLP / modulation 模块：`to_q`、`to_k`、`to_v`、`add_q_proj`、`add_k_proj`、`add_v_proj`、`to_add_out`、`to_out.0`、`img_mlp.net.2`、`img_mod.1`、`txt_mlp.net.2`、`txt_mod.1`）。
- 它**没有任何控制注入机制**（没有 `control_img_in`、没有 `control_blocks`、没有 `controlnet_x_embedder`），因此条件必须作为**参考潜在（ref）token** 从外部注入。

### 在 Nunchaku Qwen Image 上测试的注入方式

| 方式 | 结果 |
|------|------|
| ref-concat（`index`） | **双重结构伪影**：参考图像（条件）被绘制为生成图像内部的小图。内部小图确实跟随 canny 结构，但布局被破坏（画中画），无法作为正常的 ControlNet 使用。 |
| ref-concat（`index_timestep_zero`） | 内部小图变成**源图像的复制**（编辑型条件会过强地保留 ref 内容）；canny 控制实际丢失。 |
| 隔离 kv_cache 注入（Krea2 openpose 方式） | **完全无法引导生成** —— 该 LoRA 对 K/V 缓存的 ref 条件没有反应。 |

---

## 2. 关键结论

- **双重结构伪影并非 Nunchaku 特有**：即使在标准 bf16 Qwen Image 模型上，该 LoRA 也会绘制内部小图。唯一区别是 **bf16 还会渲染外部画面**，而 Nunchaku 不会。
- **model-patch 型 ControlNet**（DiffSynth block-wise、`control_block` 权重）同样**无法用于** Nunchaku Qwen Image —— 参见 v2.6.0 发行说明第 4 节：nunchaku W4A4 量化将 hidden-state 放大到远超标准尺度（实测 `to_qkv` 约 29 倍、MLP 约 760 倍、块输出均值约 1.4e5），BlockWise ControlNet 残差会被淹没，而简单的重新缩放会破坏通道结构。
- **两种自定义 ControlNet 格式在 Nunchaku Qwen Image 上均无法正常工作。**

---

## 3. 建议

对于 **Nunchaku Qwen Image**，请使用**标准（非 model-patch）ControlNet**，例如阿里巴巴的 [Qwen-Image-2512-Fun-Controlnet-Union](https://huggingface.co/alibaba-pai/Qwen-Image-2512-Fun-Controlnet-Union)，通过 ComfyUI 的**常规 Apply ControlNet 流程**使用 —— 它可以直接用于 Nunchaku Qwen Image。

---

## 4. 文档更新

- **README** —— "Known Limitations" 部分：
  - **model-patch 型 ControlNet**：补充了详细的技术背景（SVDQW4A4Linear hidden-state 放大、per-channel 尺度非均匀性（最大约 1500 倍）、约 0.3% 残差被淹没、Z-Image 通过 NextDiT 不受影响、上游 issue #711 参考）。
  - **LoRA 型 ControlNet**：补充了完整背景与测试证据（无注入机制的全量 rank-64 LoRA、ref-concat index / index_timestep_zero 结果、kv_cache 无引导、非 Nunchaku 特有的说明）。
  - **建议**：改用标准 ControlNet（阿里巴巴的 Fun-Controlnet-Union）。
